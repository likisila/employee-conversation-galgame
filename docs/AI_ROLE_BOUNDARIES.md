# AI 協作邊界（單一權威規範）

本文件是本專案 ChatGPT（包含 Codex）與 Claude 分工的唯一權威來源。每次修改任何檔案前，代理必須先分類工作；若請求跨越角色邊界，必須拆分並只完成自己被授權的部分。

## ChatGPT 的唯一責任

ChatGPT 只負責以下非程式產出：

- 文案：故事、劇情、角色設定、世界觀、台詞、選項文字、結局文字、UI 顯示文字。
- 圖片：角色圖、背景／場景圖、UI 視覺素材、提示詞與素材驗收。
- 影片：過場影片的創意、腳本、分鏡、提示詞、成品與內容驗收。
- UI 設計：視覺方向、版面稿、元件外觀、色彩、字體、間距、視覺狀態與設計規格。

ChatGPT 可以在既有資料結構中更新純內容欄位，但不得改變 schema、識別碼規則、條件、效果、路由、狀態轉移或任何會改變遊戲行為的欄位。

## Claude 的唯一責任

Claude 負責所有遊戲相關程式碼開發與 UX，包括：

- 原始碼、測試、建置、設定、依賴、工具腳本、CI/CD 與部署。
- HTML、CSS、TypeScript、JavaScript，以及任何其他可執行或影響執行結果的檔案。
- 遊戲引擎、資料 schema、驗證器、分支條件、效果、路由、存讀檔與資產載入／整合。
- UX：流程、導覽、互動、輸入、回饋、動畫行為、響應式行為、無障礙、錯誤處理、效能與易用性。
- 將 ChatGPT 提供的 UI 設計、圖片、影片與文案實作並整合進遊戲。

Claude 不自行創作文案或視覺資產；發現缺漏或矛盾時，應列出需求交回 ChatGPT。

## UI 與 UX 的判定

- UI 設計是「畫面應該長什麼樣」：由 ChatGPT 產出設計稿、規格與視覺素材。
- UX 與 UI 實作是「畫面如何運作」：由 Claude 編寫與修改程式。
- 即使目的是調整視覺，只要需要修改 HTML、CSS、元件程式碼、互動或執行設定，就屬於 Claude。

## 強制執行流程

1. 修改前先判斷每項工作屬於 ChatGPT 或 Claude。
2. ChatGPT 遇到程式碼或 UX 工作時，只能提供需求、設計規格或交接說明，不得直接修改。
3. Claude 遇到文案、圖片、影片或 UI 視覺設計工作時，只能提出素材需求或整合問題，不得代為創作。
4. 混合型任務必須拆分：ChatGPT 先交付內容／視覺規格，Claude 再完成程式與 UX 實作。
5. 每次更新前後都必須依 [AI_HANDOFF.md](AI_HANDOFF.md) 完成雙向交接；未留下交接紀錄的更新不得合併。
6. 審查變更時，任何越界檔案都必須從該代理的提交中移除並交回正確角色。
7. 只有使用者明確要求修改本分工規則時，才能變更這份文件；單一任務的便利性不得視為例外。

## ChatGPT 提交檢查

ChatGPT 在 commit 或 PR 前必須確認：

- 變更只包含文案、圖片、影片、UI 設計文件或既有 schema 內的純內容欄位。
- 沒有修改程式碼、UX 行為、schema、測試、腳本、工作流程、依賴或設定。
- 需要程式整合的部分已留下清楚的 Claude 交接事項。
- 已讀取 Claude 最新紀錄並更新 `docs/ai-handoff/CHATGPT.md`。

## Claude 提交檢查

Claude 在 commit 或 PR 前必須確認：

- 變更只包含程式開發、UX 與素材整合所需內容。
- 沒有自行新增或改寫正式文案、圖片、影片或 UI 視覺設計。
- 缺少的內容或設計已明確列為 ChatGPT 待辦。
- 已讀取 ChatGPT 最新紀錄並更新 `docs/ai-handoff/CLAUDE.md`。
