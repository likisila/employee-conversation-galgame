## Setup

公司失去主要客戶後完成裁撤決策，主管周予安直到通知前二十分鐘才拿到最後文件。林雨澄仍在修改已無未來的專案，且相信自己下季會被轉往新團隊。

## Rising Action

1. 予安選擇是否在會議邀請中說明性質。
2. 雨澄從 HR 在場與藍色資料夾察覺異常。
3. 予安必須說出決定，而不是用「調整」掩蓋。
4. 雨澄追問原因與決策時間，拒絕被要求立刻消化。
5. 文件簽署與推薦資源使制度權力變得具體。

## Climax

雨澄問：「你有沒有哪一刻，是真的想把我留下來？」予安必須回答曾做過什麼，同時拒絕把努力變成雨澄應回報的情感債；若趁此告白或提出交換，立即進入越線結局。

## Resolution

依坦誠、程序與界線分為四個結局。TRUE END 不在當天建立戀愛關係，而在所有職務關係結束後，由雨澄主動開啟一次平等的私人見面。
