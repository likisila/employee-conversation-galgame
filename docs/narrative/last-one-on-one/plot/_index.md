# Plot Structure

## Story Structure

**Model:** 壓縮三幕式，適合 20–25 分鐘單場景視覺小說。

| Beat | Time | Story Event | Player Function |
|------|------|-------------|-----------------|
| Opening | 0:00–2:00 | 予安收到最終文件，雨澄仍在改已取消專案 | 建立資訊不對等 |
| Inciting Incident | 2:00–4:00 | 玩家決定如何邀請雨澄進會議室 | 第一次測試坦誠 |
| First Plot Point | 4:00–7:00 | 必須親口說出職位已裁撤 | 進入不可逆談話 |
| Rising Action | 7:00–12:00 | 雨澄追問是否為績效、是否早已決定 | 區分清楚與卸責 |
| Midpoint | 12:00–15:00 | 雨澄拒絕立即簽字，要求帶回文件 | 程序測試 |
| Crisis | 15:00–18:00 | 她問予安是否曾想留下她 | 私人情感與職權交叉 |
| Climax | 18:00–20:00 | 玩家回答並決定是否守住界線 | 結局判定 |
| Resolution | 20:00–25:00 | 當晚或數週後的後日談 | 顯示選擇後果 |
