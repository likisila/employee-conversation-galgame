# 藍色權益資料夾

包含職位裁撤通知、適用給付與日期摘要、保險與設備處理、作品資料申請方式、提問／申訴窗口，以及「收訖不等於同意」的醒目說明。

## Narrative Function

- 玩家是否允許雨澄帶回審閱，是程序值的主要分歧。
- TRUE END 中資料夾被雨澄主動拿走；「柔軟的刀」結局中它留在桌上。
- 文件內容不寫死現實法規數字，以避免虛構作品被誤作法律範本。

Frontmatter 記錄 Choice 4 發生前的共同基準狀態：資料夾仍由微光互動持有，放在月球會議室。各結局的持有與位置分歧記錄於 `continuity/state.md`，不以非標準值覆寫索引欄位。
