# 月球會議室

六人小會議室，玻璃牆貼著卡通太空人防撞貼。預約系統顯示本次會議名稱為「1:1 Sync」，門外的人看不出內容。空調太冷，圓桌中央有三杯水與一只藍色資料夾。

## Sensory Anchors

- 冷氣壓縮機規律啟停。
- 紙張滑過木紋貼皮桌面的摩擦聲。
- 雨滴沿玻璃留下像刪除線的水痕。

## Story Function

主線談話所在地。透明玻璃象徵公司口中的透明文化，也反襯資訊早已在當事人之外決定。
