# 微光互動辦公室

位於商辦大樓十二樓的開放式辦公室。牆上標語「讓每個流程被看見」因背膠老化，最後一個字總往下掉。傍晚四點四十分，窗外開始下雨，團隊還在為已被取消的專案調整按鈕圓角。

## Story Function

- 讓日常工作與即將發生的裁撤並置。
- 讓雅琳交付資料夾、與仍不知情的雨澄擦身而過，建立近距離的資訊落差。
- 以「財務把明天也省掉了」保留黑色職場喜劇，但不岔出與當前行動無關的公司活動。
- 場景一與場景二所在地。
