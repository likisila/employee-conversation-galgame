# 對話與結局系統

系統追蹤 trust、procedure、boundary、avoidance 四個整數，不直接顯示好感度。選項回饋透過角色行為與環境音呈現。

## Design Rule

任何增加私人親密、但同時減少程序保障或利用主管權力的選項，都不得通往戀愛結局。TRUE END 必須同時通過坦誠、程序與界線門檻。

## Ending Priority

1. 越線
2. 真正的告別
3. 體面的句點
4. 柔軟的刀
