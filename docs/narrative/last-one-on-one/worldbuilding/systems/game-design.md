# 《最後一次一對一》Demo 遊戲企劃

## 一句話賣點

一款沒有「完美答案」的職場 Gal Game：你不能挽回資遣決定，只能決定自己要用權力索取諒解，還是把選擇權還給即將離開的人。

## 玩家體驗承諾

1. 20–25 分鐘內完成一場高壓談話。
2. 五次選擇都不是「善良／邪惡」按鈕，而是在清楚、逃避與越線之間作取捨。
3. 好感不是核心數值；真正影響結局的是坦誠、程序與界線。
4. 戀愛伏筆存在，但不允許玩家在仍有主管權力時用工作資源交換親密。

## 內容提醒

本作包含非自願離職、職場權力不對等、經濟焦慮與不當情感施壓。建議在開始畫面提供「略過強烈職場措辭」與隨時返回標題的選項。

## 核心狀態

| 變數 | 初始值 | 正向行為 | 負向行為 | 是否顯示 |
|------|--------|----------|----------|----------|
| 坦誠 trust | 0 | 清楚說明、承認決定已定、回答已知事實 | 誤導、卸責、把績效當藉口 | 預設隱藏 |
| 程序 procedure | 0 | 說明文件用途、給予審閱空間、提供第二窗口 | 催簽、私下承諾、模糊權利 | 預設隱藏 |
| 界線 boundary | 0 | 不索取安慰、不以推薦換沉默、讓對方主動聯絡 | 告白、肢體安撫、情感交易 | 預設隱藏 |
| 逃避 avoidance | 0 | — | 假裝聊天、公司話術、模糊主詞 | 僅除錯模式 |

數值不應以愛心呈現。若要給玩家回饋，可用很短的環境反應：空調聲變清楚、雨澄把文件推近或推遠、雅琳放下或拿起平板。

## Interactive Organizational Case 層

本作除故事結局外，必須在每次通關後提供可選的 `MBA Organizational Debrief`。分析層讀取五個主要選擇、結局與四個既有隱藏狀態，轉譯為 management credibility、information quality、perceived fairness、employee agency、psychological safety、process integrity 六項組織狀態。感情線微選擇只服務角色關係，不列入 MBA 評估。

Debrief 必須包含玩家管理路徑、stakeholder 結果、因果機制、短長期效果、unintended consequences、相關理論、替代策略及案例限制。正式內容與期末報告結構見 `property/mba-organizational-debrief.md`。

## 選擇節點

| # | 情境 | 建議選項 | 主要影響 |
|---|------|----------|----------|
| 1 | 邀請會議 | 先告知是組織與職務調整／只說聊一下／謊稱有好消息 | 坦誠、程序、逃避 |
| 2 | 開場通知 | 直接說職位裁撤且非績效／用組織優化包裝／先檢討表現 | 坦誠、程序 |
| 3 | 「所以不是來問我的？」 | 承認決定已定／強調大家都很難／暗示配合就可能翻案 | 坦誠、程序 |
| 4 | 文件與簽名 | 允許帶回審閱／要求現在簽／提出私下補償 | 程序、界線 |
| 5 | 「你有沒有想過留下我？」 | 說明曾提替代案但不要求回報／強調自己多努力／趁機告白 | 坦誠、界線 |

## 結局判定

按順序判定：

| Ending | 條件建議 | 結果 |
|--------|----------|------|
| END 04 越線 | 私下補錢，或在權力關係仍存在時告白，或 boundary ≤ -2 | 雨澄終止談話並改由 HR 接手；玩家面對正式紀錄 |
| TRUE END 真正的告別 | trust ≥ 6、procedure ≥ 4、boundary ≥ 2、avoidance ≤ 1 | 雨澄保有主動權；所有關係結束後，她主動邀請一杯不談工作的咖啡 |
| END 02 體面的句點 | procedure ≥ 4、trust ≥ 2、boundary ≥ 0 | 對話不溫暖但完整；兩人以推薦與告別收束 |
| END 03 柔軟的刀 | 其他 | 漂亮話讓資訊與責任更模糊；雨澄拒絕私人聯絡 |

「私下補錢」與「在權力關係仍存在時告白」是不可被後續正向選擇抵銷的重大越線，兩者都直接進入 END 04。其他行為仍依 boundary 累計判定。結局不以平均分布為目標，TRUE END 維持刻意嚴格的門檻。

## 玩法倫理

- 不設「讓她接受資遣」或「讓她不生氣」的勝利條件。
- 雨澄拒絕簽字、拒絕握手、離席都不是懲罰玩家，而是角色合理行使主體性。
- TRUE END 也不讓雨澄感謝被資遣；她只肯定玩家在無法改變結果後仍選擇誠實。
- 戀愛訊號發生在離職生效、設備返還、權益確認與推薦信完成之後；訊息由雨澄先發。
- 不把 HR 寫成阻礙愛情的反派。雅琳是程序與界線的見證人。

## 視聽建議

### 場景

- 傍晚開放辦公室：冷灰藍、螢幕反光、遠處 Slack 提示音。
- 月球會議室：玻璃牆、圓桌、過度可愛的太空貼紙；桌上三杯水只有兩杯被碰過。
- 雨夜騎樓：結局轉場，霓虹映在積水。
- 零號月台咖啡：只在 TRUE END 使用，暖橘燈光但保留城市噪音。

### 角色表情最小集

| 角色 | 必要表情 |
|------|----------|
| 雨澄 | 平常、警覺、空白、壓怒、自嘲微笑、放鬆 |
| 雅琳 | 中性、制止、疲倦幽默 |
| 予安 | 第一人稱可不做立繪；以手、文件與玻璃倒影呈現 |

### 音效與配樂

- Slack 通知、冷氣壓縮機、紙張滑過桌面、電子錶提示音、雨聲。
- 開場使用幾乎聽不見的低頻節拍；通知說出口時短暫抽掉音樂。
- TRUE END 不用勝利音效，只讓咖啡機蒸氣聲接回主旋律。

## CG 建議

1. **關鍵 CG：** 藍色權益資料夾位於桌面中央，三人的手都沒有碰它。
2. **分歧 CG：** 雨澄把識別證翻面，呼應予安進門前的動作。
3. **TRUE END CG：** 咖啡店玻璃映出兩人並肩、沒有公司識別證的身影。

## 正式版擴充方向

- 共通線即本 Demo；後續不是再攻略「被資遣的雨澄」，而是描寫兩個已離開主管／部屬關係的人重新認識。
- 可加入雅琳視角的短篇，呈現 HR 如何在制度內阻止二次傷害。
- 其他可攻略角色若增加，應避免全部都是受玩家職權控制的員工；可改為前同事、客戶端夥伴或離職後社群認識的人。

## 法務與敘事檢核

- 正式製作前，由台灣勞動法專業人士審閱通知、給付、預告、文件與申訴段落。
- 不把虛構腳本當成主管實務訓練教材。
- 若以真實公司經驗改編，需移除可識別人物、專案與薪資資訊。
