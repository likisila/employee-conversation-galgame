# 微光互動

約四十人的 B2B SaaS 新創，公開價值是「清楚、勇敢、一起發光」。失去占營收近半的客戶後，公司裁撤與該專案高度綁定的職務，同時要求主管使用「組織優化」一詞。

公司不是單一反派，而是一套讓每個人都能說「不是我決定」的責任稀釋機制。

## Decision Topology

- 決策層掌握編制與裁撤名單；名單核准後，予安與雅琳都無權撤回。
- 其他團隊仍需要設計產能，卻沒有核准職缺，因此「把人轉過去」只能是未獲授權的想像，不能當承諾。
- 予安能分配工作、寫推薦並說明作品；這些剩餘資源讓他的善意仍帶有交換壓力。
- 雅琳能更正資訊、管理文件與窗口、留下紀錄並終止越線談話；她守得住程序，改不了結果。
- 雨澄無法參與職位決策，但能拒簽、審閱、提問、換窗口，以及決定後續是否聯絡。
