# Pulled cutscene videos（隔離舊片，僅供比對）

這裡保存已從 `public/assets/cutscenes/` 下架的舊影片。它們不屬於 [分鏡表 v3](../../../property/cutscene-storyboard-v3.md) 的交付物，也不得因檔名相同而直接放回正式素材目錄。

> 2026-09-27 新增的 [`00-v4-candidate-01/`](00-v4-candidate-01/) 不是下列隔離舊片，而是依 v4 將 00-A／B／C 本地硬切完成的待審候選。它仍未獲使用者核准，不得移入正式素材或接 runtime；來源、順序與雜湊見該資料夾 README。

## 為何全部維持隔離

- 兩支舊片都使用改版前的曾雅琳：深色／黑髮、深色套裝，違反現行「肩長淺冷灰棕髮、淺灰米色西裝外套、霧灰上衣、淺灰長褲、米白鞋」設定。
- v3 已重寫段落功能、鏡頭數與插入點；舊片即使單格好看，也不能直接接回目前劇情。
- `property/sora-cutscenes.json` 的檔名是未來交付契約，不代表隔離區同名影片已通過內容驗收。

## 重新啟用條件

只有依 v3 核准關鍵影格重新生成、完成剪輯與實機驗收的新影片，才可放進 `public/assets/cutscenes/`。隔離舊片永久保留為歷史比對資料，不作候選成片。
