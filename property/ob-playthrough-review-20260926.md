# 組織行為課程 Playthrough Review（2026-09-26）

> 課程定位：組織行為（Organizational Behavior，OB），不是 HR。HR、裁撤通知與文件程序是案例情境；本次評估依 `mba-organizational-debrief.md` 的「課程定位與 Review 門檻」進行。

## 一、實機覆蓋

本次從故事內正常選擇與「回到之前的選擇」完成四個結局，並逐一開啟最後的「查看案例分析」：

| 結局 | 代表管理路徑 | 主要 OB 機制 |
|---|---|---|
| TRUE END：真正的告別 | 清楚邀請／直接命名／承認已決／保留審閱／提供資源但不索取回報 | informational justice、agency、psychological safety、ethical leadership |
| END 02：體面的句點 | 前四項維持程序保障，最後把曾經爭取轉成情感帳 | compliance 不等於 trust、social exchange、LMX |
| END 03：柔軟的刀 | 模糊邀請／委婉命名／轉移到主管情緒／催促簽收／最後不索取回報 | impression management、emotional labor、voice suppression |
| END 04：越線 | 前段透明，但以私人金錢介入正式補償；最後仍不索取回報 | power-dependence、implicit debt、boundary crossing |

另以 390×812 行動版檢查 END 03 的完整分析面板：頁面寬度 390px、面板寬度 375px，沒有水平溢出；兩個操作按鈕均完整容納文字。四路線操作期間瀏覽器沒有 error／warning。

## 二、對白與場景判定

### 通過

1. 三位角色的說話行動可辨：雨澄以具體工作語言追問資訊與責任；雅琳以程序語言劃出權利與角色衝突；予安的措辭會隨玩家選擇在承擔、逃避、交換與越線之間改變。
2. 對白不直接講授理論，而是讓理論存在於行為與後果中；「只是收訖」、「你不欠我」、「私下補一筆」等句子都能讓玩家感受 agency、exchange 與 dependence 的差異。
3. 藍色資料夾、電子錶、簽收文件、訊息輸入框等道具持續承載權力與延遲後果，不只是場景裝飾。
4. 四個結局的價值落點清楚不同：程序與關係可分離、善意可以成為壓力、越線會污染先前的正向行為。這些差異符合 OB 案例，而不是單純的好／壞 HR 流程。

## 三、最後評估頁判定

### 已符合 OB 的部分

1. 評估不顯示隱藏分數，也不把玩家貼上好主管／壞主管標籤。
2. 六項組織狀態涵蓋可信度、資訊品質、公平、主體性、心理安全與程序完整，方向正確。
3. 因果鏈能把玩家原句連到組織機制與延遲後果；END 04 能清楚指出私人補償如何形成情感債務。
4. 四位 stakeholder 都有結果，且頁面承認沒有單一最佳答案與案例限制。

### 尚未通過完整教學閉環的部分

1. **理論只有英文名稱，沒有解釋。** 玩家看到 `Procedural Justice`、`Power-Dependence` 等名詞，卻看不到「本路徑的哪個行為啟動了什麼機制、為何造成這個結果」。`mba-debrief.json` 已有各結局 `theoryNote`，但目前畫面未呈現。這使頁面比較像名詞索引，尚不足以教育玩家的決策。
2. **組織狀態的證據可能與等級方向相反。** END 03 的管理可信度、資訊品質與心理安全皆為「脆弱」，證據卻是正向的「提供事實與資源但不索取感謝或聯絡」；END 04 的心理安全被重大越線封頂為「脆弱」，仍顯示同一正向證據。玩家會無法判斷究竟是哪個決策造成風險，也可能誤以為正向行為受罰。
3. **「換一種做法」只有一個策略。** 正式規格要求兩個替代策略，各自呈現改善與犧牲；目前無法比較兩種可行但代價不同的管理選擇。
4. **利害關係人分析被壓縮成結果句。** 畫面沒有帶出 stakeholder matrix 中的正式權力、資訊差與主要風險；尤其「微光互動／決策層」目前顯示的是整體管理策略摘要，不是該 stakeholder 自己承擔或外部化的後果。
5. **理論與因果鏈的選取過度受絕對分數影響。** 代表路徑中重複出現程序公平、權力依賴等理論，但未必優先說明該結局最具辨識度的機制，例如 END 02 的 compliance／trust 分離、END 03 的 emotional labor、END 04 的 implicit debt。

## 四、後續 Review 的驗收標準

下一次實作後，四個結局都應能回答下列問題，才算最後評估頁完成 OB 學習閉環：

1. 我做了什麼可觀察行為？
2. 這個行為改變了哪一種權力、資訊、voice、公平、信任或心理安全機制？
3. 哪位 stakeholder 在短期得利、長期承擔代價？
4. 畫面引用的證據是否與該維度的「高／中／脆弱／低」方向一致？
5. 至少兩個替代方案各改善什麼、犧牲什麼？
6. 理論名稱是否附上本路徑可理解的中文解釋，而不是只列術語？

## 五、總評

故事、對白與主要決策已能讓玩家感受並討論組織行為；四個結局也具有可比較的權力與關係後果。**目前可作為 OB 案例使用，但最後評估頁仍需要修正證據歸因並補上理論解釋，才足以獨立完成「玩家能理解、能反思、能提出替代決策」的教學目的。**
