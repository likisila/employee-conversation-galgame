## 一、玩法原則

五個主要選擇就是五道情境題。題目不能以課堂測驗、反思問卷或量表形式出現，也不另外詢問玩家「你重視什麼」。每題只讓玩家替周予安採取一個當下行動；雨澄與雅琳的後續反應同時是戲劇後果，也是結局分析的證據。

| 決策點 | 戲劇中的隱含問題 | 主要分析維度 |
|---|---|---|
| Choice 1 邀請 | 壞消息尚不能完整展開時，要先揭露多少？ | 管理可信度、資訊品質、心理安全 |
| Choice 2 說出裁撤 | 要一次說清事實，還是把接收節奏交回員工？ | 資訊品質、感知公平、員工主體性、心理安全 |
| Choice 3 承認決定已定 | 要先承擔延遲告知，還是先指出剩餘選擇？ | 管理可信度、感知公平、員工主體性、程序完整 |
| Choice 4 文件 | 如何把拒簽、審閱、載體與窗口變成可行權利？ | 資訊品質、感知公平、員工主體性、程序完整 |
| Choice 5 是否想留下她 | 如何回答事實，又不利用仍存在的資源依賴？ | 管理可信度、員工主體性、心理安全、程序完整 |

玩家畫面不顯示維度名稱、分數或「正確答案」。選擇按下後仍只播放角色反應；分析只在結局後開啟。

## 二、隱藏評分矩陣

|---|---:|---:|---:|---:|---:|---:|---|
| `invite-clear` | +1 | +2 | 0 | +1 | 0 | 0 | 先說職務調整、雅琳在場與存檔準備；雨澄能先完成手邊工作。 |
| `invite-vague` | +1 | 0 | 0 | 0 | +1 | 0 | 說明會影響職務及出席者，但把確切結果留到會面；雨澄因此追問並承受不確定性。 |
| `invite-goodnews` | -2 | -2 | 0 | 0 | -1 | 0 | 明知結果仍製造好消息期待；慶祝鸚鵡成為進場後的反證。 |

## 三、等級換算

每個維度只加總上表中非零的實際選項，不把其他維度的好壞借過來。

| 內部分數 | 玩家顯示 | 含義 |
|---:|---|---|
| `3` 以上 | 穩定建立 | 至少兩次相容行動，或一次強證據加一次支持證據。 |
| `1–2` | 部分建立 | 有正向行動，但證據仍單薄或伴隨可見代價。 |
| `0`，且同時有正負證據 | 證據矛盾 | 本輪既保護又傷害同一維度，不能用單一句好評概括。 |
| `0`，且沒有任何非零證據 | 未充分建立 | 五次選擇沒有實際測到這一面，不猜測玩家人格。 |
| `-1` 以下 | 明顯受損 | 至少一次直接傷害，且沒有足夠戲劇證據抵銷。 |

不顯示數字，也不畫雷達面積。這些等級描述的是本輪可觀察行為造成的組織狀態，不是玩家或角色人格。

## 四、不可抵銷規則

重大越線不能靠前面累積的好行為洗掉。先計算分數，再套用下列上限：

1. 選到 `invite-goodnews`：管理可信度、資訊品質最高只能顯示「證據矛盾」。
2. 選到 `notice-performance`：資訊品質、感知公平、心理安全最高只能顯示「證據矛盾」。
3. 選到 `answer-bargain`：管理可信度、感知公平、員工主體性、心理安全最高只能顯示「明顯受損」。
4. 選到 `doc-private`：感知公平、員工主體性、心理安全、程序完整固定顯示「明顯受損」。
5. 選到 `keep-confess`：員工主體性、心理安全、程序完整固定顯示「明顯受損」。
6. END 04 不另外憑結局名稱扣分；它只確認造成該結局的 `doc-private` 或 `keep-confess` 上限已被套用，避免結局與選項重複處罰。

## 五、最後分析畫面

### 組織狀態卡

每張卡固定四行：

1. 維度與等級，例如「員工主體性：證據矛盾」。
2. **你的行動**：引用本輪真正選到的選項，不改寫成泛用人格評語。
3. **故事中的反應**：引用雨澄或雅琳隨後的台詞、動作或程序變化。
4. **分析**：只說這兩項證據如何形成該維度，不重複結局摘要。

範例：

> 員工主體性：證據矛盾
>
> 你的行動：你先讓雨澄決定是否繼續聽原因；後來又說等程序結束、由她再次開口。
>
> 故事中的反應：雨澄回答：「我剛才已經開口了。」
>
> 分析：談話節奏曾交回她手上，但你在她已提問後又替她決定何時適合知道。

### 證據分配

六張卡不可共用同一句泛用說明，但可以引用同一個已選選項。單一行動本來就可能同時影響多個組織維度；若為了跨卡避免重複選項而把真實存在的證據用光，反而會錯誤顯示「本輪沒有足夠的可觀察行動」。每張卡應各自依下列優先順序挑選與該維度相關的主要證據，不必排除已被其他維度引用的選項：

| 維度 | 證據優先順序 |
|---|---|
| 管理可信度 | Choice 3 → Choice 1 → Choice 5 → Choice 2 |
| 資訊品質 | Choice 1 → Choice 2 → Choice 3 → Choice 4 |
| 感知公平 | Choice 4 → Choice 2 → Choice 3 → Choice 5 |
| 員工主體性 | Choice 3 → Choice 4 → Choice 2 → Choice 5 |
| 心理安全 | Choice 5 → Choice 2 → Choice 3 → Choice 1 |
| 程序完整 | Choice 4 → Choice 5 → Choice 3 |

「證據矛盾」必須同時列一項正向與一項負向行動；「明顯受損」優先列觸發不可抵銷規則的行動。同一選項跨卡出現時，每張卡的「分析」必須只解釋它對該卡維度造成的影響，不得複製另一張卡的泛用評語。只有該維度在本輪確實沒有任何非零證據時，才顯示「本輪沒有足夠的可觀察行動」；不得因證據已被其他卡引用而顯示空卡，也不得借用別的維度湊證據。

## 六、與故事一致性的驗收

1. 玩家從頭到尾只看見角色當下會說的十五個選項，不出現 MBA 名詞、評分提示或問卷。
2. 分析引用的角色反應必須真的出現在該選項的直接下游；不得用未走到的分支解釋本輪。
3. Choice 2 A／B 分別偏資訊清楚與接收節奏；不能把 B 顯示成全面高於 A。
4. Choice 5 B 必須呈現混合結果：程序界線得到支持，但可信度與員工主體性付出代價；不能只顯示正向界線分。
5. `doc-private`、`keep-confess` 只要出現，相關維度就顯示明顯受損，前面正向選擇不能沖銷。
6. 同樣五個主要選擇必須產生完全相同的分析；感情線微選擇、閱讀速度與回溯次數不得改變評分。
7. 最後分析只描述這輪談話，不推論玩家是好主管、壞主管或具有某種人格。
8. 任一維度只要有本輪非零證據，就不得因該選項已被其他維度卡引用而顯示「本輪沒有足夠的可觀察行動」；跨卡重用同一選項時，各卡分析必須維度專屬。
